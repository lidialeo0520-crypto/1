STELLIVE STAR COLLECTOR Android 프로젝트

이 프로젝트는 v18 HTML 게임을 Android WebView 앱으로 감싼 오프라인 실행용 Android Studio 프로젝트입니다.

APK 빌드 방법:
1. Android Studio에서 이 폴더를 엽니다.
2. Android SDK 플랫폼 35 및 Android Gradle Plugin 의존성을 설치/동기화합니다.
3. 메뉴 Build > Build Bundle(s) / APK(s) > Build APK(s)를 선택합니다.
4. 생성된 APK는 app/build/outputs/apk/debug/app-debug.apk 에 있습니다.

네트워크 권한을 선언하지 않았으며 게임 파일은 앱 내부 assets에서 로드됩니다. 따라서 게임 플레이에 인터넷 연결이 필요하지 않습니다.
