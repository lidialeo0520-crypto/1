휴대폰만으로 APK 만들기 (GitHub Actions)

1. GitHub 계정에 로그인하고 새 저장소(repository)를 만듭니다. 예: stellive-android
2. 이 ZIP을 압축 해제한 뒤, 안의 STELLIVE_ANDROID 폴더에 있는 파일과 숨김 폴더 .github까지 저장소에 업로드합니다.
   - GitHub 웹에서 Add file > Upload files를 선택합니다.
   - .github/workflows/build-apk.yml 파일도 반드시 포함해야 합니다.
3. 저장소의 Actions 탭을 엽니다. 처음이면 안내에 따라 Actions를 활성화합니다.
4. 왼쪽의 “Build Android APK” 워크플로를 선택하고 “Run workflow”를 누릅니다.
5. 실행이 끝나면 해당 실행 기록 아래 Artifacts에서
   “stellive-star-collector-debug-apk”를 다운로드합니다.
6. 다운로드한 ZIP을 풀면 app-debug.apk가 있습니다. Android에서 APK를 열어 설치합니다.

참고:
- 이 방법은 GitHub 계정과 인터넷 연결이 필요합니다(빌드할 때만).
- 완성된 앱은 게임 파일을 앱 안에 포함하므로 설치 후 오프라인으로 플레이할 수 있습니다.
- debug APK는 개인 테스트용입니다. 공개 배포용 서명 APK와는 다릅니다.
